# Rappel d'utilisation des commandes Git
  
1. Pour cloner un repository  
  
    git clone [Lien vers le repository]
  
(Sur GitHub, aller dans le repository, cliquer sur Code, cliquer sur Local, cliquer sur HTTPS, puis copier le lien du clone)  
  
2. Pour récupérer les mises à jour sur le repository en ligne
  
    git pull  
  
3. Pour ajouter les fichiers modifiés localement au commit
  
    git add .                       Pour ajouter tous les fichiers  
    git add [fichier 1] [fichier 2] Pour ajouter des fichiers en particulier  
  
(NB : git status -> permet de vérifier les fichiers qu'on a ajouté)  
  
4. Pour commit les fichiers ajoutés
  
	git commit -m [commentaire]  
  
(Toujours ajouter un commentaire à un commit pour avoir un résumé des changements effectués)  
  
5. Pour envoyer les fichiers sur le repository en ligne
  
	git push
